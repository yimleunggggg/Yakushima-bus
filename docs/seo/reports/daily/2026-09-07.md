## 三、为什么会这样

| 现象 | 说明 |
| --- | --- |
| 美国/欧洲用户但互动 0s | 多为爬虫/VPN（已剔除：Netherlands(1), Thailand(1)…）。自测加 ?ga_internal=1。 |
| GA4 总用户 383 vs 可分析 381 | 总用户含 bot；可分析=去掉互动0%+均时0s的国家行。 |
| 判断「有人在用」 | 多着陆页+互动率不低，在查时刻表/地图。 |
| ⚠ 告警 | 若你本人用欧洲节点 VPN 测站且未加 `?ga_internal=1`，会计入此类。 |
| 洞察 | 已排除 **疑似 bot** 2 用户 / 2 会话（Netherlands(1), Thailand(1)）：互动 0% 且均时 0s。**可分析**：约 381 用户 / 515 会话。 |
| 洞察 | 自然搜索占 **79%**（406 会话）：SEO 开始起量，与 GSC 点击交叉验证。 |
| 洞察 | 欧盟/英国用户 **6**（Germany(2), Belgium(1), Croatia(1), Italy(1), Spain(1)），互动率均值 **33.3%**、会话≈用户：更像 **单次跳出/爬虫/VPN**，暂不能当真实旅客。 |
| 洞察 | 多着陆页 + 7 日互动率 **65.8%**：有人在用时刻表/地图等工具，非纯误点。 |
