### 2.0 这些指标是什么意思

| 指标 | 怎么读 |

| 美国/欧洲用户但互动 0s | 多为爬虫/VPN（已剔除：Serbia(0)…）。自测加 ?ga_internal=1。 |
| 判断「有人在用」 | 多着陆页+互动率不低，在查时刻表/地图。 |
| 洞察 | 自然搜索占 **82%**（375 会话）：SEO 开始起量，与 GSC 点击交叉验证。 |
| 洞察 | 欧盟/英国 **6** 用户、互动率 **54.6%**：有实际浏览行为，可能含欧州赴日旅客或英文搜索；仍建议对照着陆页是否多页访问。 |
