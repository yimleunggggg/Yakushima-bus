# 攻略目录与正文阅读层级调整

用户反馈：整个页面排版乱、密集，文字堆砌；改善信息层级和视觉交互，同时保留内容丰富度。延续三语、官方出处和现有发布要求。

## 改动

- 目录突出无车2晚3天规划，住宿和雨天为两个次级入口，鹿儿岛独立分区；短展示标题与一句摘要用于选题，正文和搜索标题保留完整信息。
- 去掉攻略页阅读背景的细纹，采用安静底色和明确的主次字号、间距、分隔与焦点状态。样式作用于攻略目录、三篇独立正文及无车攻略。
- 正文加入页内目录，桌面固定侧栏，平板与手机为两列快捷跳转；行程改成三天时间线，订房五问改成逐项清单。
- 正文全部保留，官方出处放在原生可展开区域，非官方定位仍在正文顶部可见；页尾支持和反馈保留，降低视觉权重。
- 修正共享语言事件监听目标：所有页面从window接收语言切换，避免旧页面走备用语言处理时页尾不刷新。移除AppCore重复刷新，统一使用该事件；无车攻略在主导航归入攻略。

## 验证

- 原始`sources/guides.json`的标题、摘要、章节标题与99段三语正文逐项对比未改；生成HTML仍包含全部正文内容（五问仅改变排版和标点分隔）。
- CUA浏览器实测390×844下12页36次JA/ZH/EN切换：文档语言、URL、主导航、页尾及攻略内部链接一致，无横向溢出。
- 768和1280宽度下五个攻略页面各三语，共30组布局检查，无溢出、无缺失正文分段、导航高亮正常。
- 页内跳转实际定位到目标章节（顶部90px，避开导航）；来源可用Enter展开，官方链接保留。
- `build_seo.py`、`sync_transport_assets.py`、`seo_check.sh`及`build_all.py --validate`通过；41项Node测试通过。11个可索引页面、33个语言版本，intro仍noindex且不进入sitemap。
- 仅目录与四篇攻略更新modified至2026-10-25；交通改订日、核查日期和票价班次未改变。
