# 全站主题与导航统一

用户明确要求跨页面画风、主标题和字号保持一致，并缓解手机六项导航拥挤的问题。本轮按全站处理，不再只改攻略页。

## 实现

- 保留森林绿与暖白配色，所有页面共用纯色底、字体族、标题层级、圆角、按钮、页脚支持及反馈样式。常规字号归入共享变量：辅助文字12px、标签13px、正文14px、项目16px、分区18px，主标题手机22px、宽屏24px；交通时间和金额保留数据强调。
- 根据只读GA4页面及设备汇总，导航保留时刻表、票价、地点地图三项常用任务；船运、旅行体验、攻略、介绍及关于放入“更多”。新攻略上线时间短，不把尚未积累的流量当作内容无价值。
- 所有设备和页面使用同一个导航渲染器。采用普通按钮控制链接区域，展开状态、当前页、Tab顺序、Esc关闭并返回触发按钮、焦点离开及点击外部关闭均有实际验证。
- 沿用`nav_click`事件，增加`nav_group`区分常用/展开入口，并增加`nav_more_open`，用于之后观察入口发现情况；不宣称改版已经提升转化。
- 攻略`guide-layout`与原地点地图同名，宽屏下会互相套用网格及高度限制。改为专用`guide-reading-layout`，地图保留自己的布局；同时修正手机地图页导航边距与菜单层级。
- 没有修改交通事实、票价、原有正文或SEO标题描述。未批量刷新内容日期；新资源哈希应用到全部页面，包括事件脚本。

## 验证

- CUA覆盖12页 × JA/ZH/EN × 320/390/768/1280宽度，共144组：主标题字号、字体、14px正文、页面与导航边界、语言和页尾同步均通过。
- 另一组144次导航检查通过：三个常用链接、五个展开入口、当前页、语言参数、菜单展开及Esc恢复焦点。
- 实操白谷4班查询与经停站展开，票价选择机场后读到¥590，地图温泉筛选5条、全屏进出、菜单层级与次级船运页跳转。
- 攻略阅读容器已不再受地图500px高度限制，住宿五问仍为5项；内容和SEO编辑源未变。
- SEO/GEO生成、资源同步、SEO检查及完整构建校验通过，41项既有Node测试通过。11个可索引页面、33个语言版本，intro继续noindex。
